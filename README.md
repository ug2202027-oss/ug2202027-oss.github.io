# BrickBD - Brick Marketplace

This repository contains the database structure documentation for the BrickBD marketplace system.

## Documentation

- **[Database Structure](DATABASE.md)** - Complete ER diagram and table documentation
- **[Live View](https://brickbd.me)** - Interactive database diagram visualization (hosted via GitHub Pages)

## Overview

BrickBD is a comprehensive brick marketplace system featuring:
- Multi-user support (customers, sellers, admins)
- Product catalog with images and descriptions
- E-commerce functionality with order management
- Rating and review system
- Real-time chat communication
- Content moderation and reporting
